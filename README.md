# StudyHub

StudyHub is a student productivity web app that I built to make managing university life a little less overwhelming.

As a university student, I wanted one place where I could keep track of my courses, assignments, exams, smaller study tasks, and grades instead of having everything spread across different apps and notes. StudyHub started as a way to solve that problem for myself, and has grown into an ongoing project where I can practice building a real application from the ground up.

## Features

- **Dashboard** — View upcoming assignments, exams, and tasks at a glance.

- **Course Management** — Add, edit, delete, and organize courses with custom colors.

- **Assignment Tracking** — Keep track of assignment due dates, priorities, grades, and course weight.

- **Exam Tracking** — Record upcoming exams, their dates, times, locations, and weight.

- **Task Management** — Create smaller study tasks, organized by date, and mark them as completed.

- **Grade Tracking** — Calculate your current grade based on completed assignments and exams.

- **Calendar** — View academic deadlines and events in one place.

- **Local Storage** — StudyHub data gets saved directly in the browser so it persists between sessions.

## Why I Built It

I wanted to build something that I could actually use throughout university while strengthening my skills in front-end development and JavaScript.

Rather than following a tutorial for a simple to-do list, I wanted StudyHub to grow into a more complete application with multiple interconnected features, persistent data, and a focus on solving problems I actually encounter as a student.

StudyHub is also a learning experience that evolves as I use it. As I continue using it throughout university, I notice new things that could be improved or features that would make it more useful. I use those ideas to guide what I build next, allowing the application to grow alongside my own needs and understanding of development.

With each new feature, I'm continuing to practice JavaScript logic, DOM manipulation, data management, UI design, and structuring a larger application with multiple features that interact with each other.
